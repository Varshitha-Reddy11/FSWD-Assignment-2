
# Question 2: React Component Life Cycle - Digital Clock

## Aim
To demonstrate the life cycle methods of a React class component using a digital clock.

## Life Cycle Methods
- componentDidMount(): Starts the timer when the clock is mounted.
- componentDidUpdate(): Logs whenever the clock updates.
- componentWillUnmount(): Clears the timer when the clock is removed.

## Features
- Displays the current time.
- Updates the time every second.
- Show/Hide button mounts and unmounts the clock.
- Logs life cycle phases in the browser console.

## How to Run
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

## Technologies
React.js, JavaScript, Vite
