
# Question 1: Parent-Child Communication Using Props

## Aim
To demonstrate parent-child communication in React using props and callback functions.

## Components
- App: Stores the items and handles adding and deleting.
- ItemForm: Accepts a new item and sends it to the parent through a callback prop.
- ItemList: Displays the items and provides a Delete button.

## Concepts Used
- React props
- useState Hook
- Callback functions
- Event handling
- Array map() and filter() methods

## How to Run
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
