
# Question 3: Timed Quiz Application

## Aim
To develop a timed multiple-choice quiz using React.

## Features
- Displays one question at a time.
- Contains five multiple-choice questions.
- Uses useEffect for the countdown timer.
- Automatically submits when time reaches zero.
- Calculates and displays the final score.
- Supports manual submission and restarting the quiz.

## Technologies
React.js, JavaScript, Vite
